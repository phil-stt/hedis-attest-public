# v2 held-out labels: review sheet

Generated from the scenario libraries by `scripts/generate_data_v2.py`. One chart per (provider-group tranche, measure, category) for CBP, GSD, COL-E; for TRC (per indicator) and KED, one chart per (measure, category) in each of two rotating tranches. Review each row against its documents before the first v2 eval run; edit `v2-heldout.json` directly if a label is wrong. Documents are in the store after `python -m attest.seed import-data --bundle data/v2/eval-block.jsonl.gz`; the app shows them at /gap/<id>.

For `none` rows there is no evidence passage: check that the documents contain nothing that closes the gap. `secondary` means the evidence document came from a source other than the tranche's primary one, under that source's own identifier. For independent practices the primary source is the fax inbox, so most documents carry a FAX reference even when primary.
